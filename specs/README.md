# Спецификации реализации реферального API

Эти задания предназначены для последовательного выполнения моделью GPT‑5.6 в этом репозитории. Это план реализации, а не отчёт о выполненной работе. Основание: корневой `README.md` и текущий PHP-код.

## Порядок выполнения

1. [Данные и бизнес-правила](01-data-and-domain.md).
2. [Контракт и реализация API](02-referral-api.md).
3. [Запуск через Docker Compose](03-docker-compose.md).
4. [Scribe и экспорт в Postman](04-scribe-postman.md).
5. [Тесты и итоговая приёмка](05-tests-and-acceptance.md).

Каждый этап использует результат предыдущего. Тесты на изменяемое поведение добавляй в соответствующем этапе; пятый этап собирает полную проверку. Не считай отсутствие окружения успешной проверкой.

## Общие инструкции модели

- Перед работой прочитай `AGENTS.md`, исходный `README.md`, эту страницу и выбранную спецификацию. Проверь актуальное состояние файлов: оно могло измениться после составления specs.
- Реализуй задачу, а не только предложи план. Сохраняй существующие незакоммиченные изменения пользователя; не выполняй `git reset`, не создавай коммиты и не публикуй репозиторий без отдельного поручения.
- Используй Laravel 12, PHP 8.2+ и версии из `composer.lock`. Не обновляй зависимости без необходимости. Для API сторонних пакетов сверяйся с установленной версией и её официальной документацией.
- Сохраняй простую архитектуру: контроллер, существующий сервис, модели и observer. Не добавляй интерфейс пользователя, настоящую авторизацию, очередь, платёжный API или механизм выплат.
- Контракт JSON и решения по ошибкам ниже — проектные решения этих specs: исходное задание разрешает выбрать формат самостоятельно.
- Поведение начислений из исходного кода имеет приоритет над предположениями о том, как должна работать реферальная программа. Не исправляй необычные правила без отдельного задания.
- При завершении этапа перечисли изменённые файлы, проверки и их результат. Если проверка заблокирована окружением, укажи причину и команду для воспроизведения.

## Стартовый запрос для GPT‑5.6

```text
Прочитай AGENTS.md и specs/README.md. Выполни specs/01-data-and-domain.md:
внеси изменения в код, добавь необходимые проверки и проверь критерии приёмки.
Сохрани незакоммиченные изменения пользователя. В конце сообщи результат
проверок и оставшиеся ограничения. Не переходи к следующему этапу.
```

Для следующего этапа замени путь к спецификации. Для выполнения всего задания явно поручай пройти этапы 01–05 по порядку.
